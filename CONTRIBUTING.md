# Contributing

Thanks for helping keep this guide accurate and useful!

## How to contribute

1. **Open an issue** — For suggestions, corrections, or new resources you'd like to see added
2. **Open a pull request** — For direct edits to the README or supporting files
3. **Discussions welcome** — Use GitHub Issues for debate on interpretations, grey areas, and policy developments

## Guidelines

- **Cite sources.** Link to the regulation text, official guidance, or reputable analysis for factual claims
- **Be precise about dates and deadlines.** The timeline is complex; double-check before updating
- **Distinguish fact from interpretation.** Use "likely," "may," "arguably" where the law is unsettled
- **No legal advice.** This is an informational resource, not a substitute for qualified counsel
- **Keep it actionable.** OSS maintainers need practical guidance, not just legal theory

## What we need most

- Updates when new Commission guidance is published
- Links to enforcement actions and court decisions as they emerge
- Case studies from OSS projects navigating compliance
- Translations of the guide into EU languages
- New compliance tools as they're released
